# 封禁售卖锁定与归属人筛选设计

日期：2026-07-27

状态：待最终确认

## 1. 目标

调整抖音账号后台的售卖状态规则，并为归属人增加与售卖状态、账号状态一致的列表筛选能力。

本次变更包含：

- 新账号默认售卖状态从“未售卖”改为“已找回”
- 账号状态为“封禁”时，服务端永久锁定售卖状态为“已停用”
- 列表增加归属人下拉筛选
- 新增和编辑表单复用数据库中已有归属人作为输入建议
- 归属人筛选同步影响列表、URL 和导出结果

本规格覆盖并替代原设计中“售卖状态与账号状态永远互不修改”的规则。两组状态仍然独立管理，唯一例外是本规格定义的“封禁 ⇒ 已停用”强制约束。

## 2. 封禁账号售卖规则

“封禁 ⇒ 已停用”是服务端不可破坏的数据规则，前端显示不能代替服务端校验。

规则在以下路径统一执行：

1. 新增账号：检测结果为封禁时，无论请求提交何种售卖状态，都保存为“已停用”。
2. Excel/CSV 导入：检测结果为封禁时，忽略导入行中的其他售卖状态并保存为“已停用”。
3. 修改抖音号：新抖音号检测结果为封禁时，同步将售卖状态设为“已停用”。
4. 单条重新检测：检测结果为封禁时，同步将售卖状态设为“已停用”。
5. 批量重新检测：复用单条检测规则，每个检测为封禁的账号同步设为“已停用”。
6. 服务启动：把历史数据中账号状态为封禁、售卖状态不是已停用的记录统一修正为“已停用”。

封禁通常是永久状态，因此本期不设计从封禁自动恢复为正常或违规，也不自动把“已停用”恢复为“已找回”。

管理员不能把封禁账号的售卖状态改成其他值：

- 单条编辑返回明确错误，不保存其他字段，避免出现部分成功。
- 批量修改只要包含封禁账号且目标状态不是“已停用”，整次请求拒绝，并返回被锁定账号数量。
- 修改归属人等不涉及售卖状态的操作仍允许执行。

## 3. 默认售卖状态

共享输入契约和新增账号表单的默认售卖状态改为 `recovered`，界面显示“已找回”。

导入文件的售卖状态为空时使用“已找回”；如果文件明确填写其他合法状态则按填写值保存，封禁规则优先级最高。

已有非封禁账号的售卖状态不做批量迁移。

## 4. 归属人下拉与数据同步

API 增加受管理员会话保护的归属人选项接口：

```text
GET /api/accounts/owners
```

返回数据库账号中的非空归属人，去重后按中文排序：

```json
{
  "items": ["小王", "张三"]
}
```

列表查询增加可选的精确匹配参数：

```text
GET /api/accounts?owner=张三
```

前端行为：

- 工具栏在“账号状态”之后显示“归属人”下拉框。
- 第一项为“全部归属人”，其余选项来自 `/api/accounts/owners`。
- 选择后写入 URL 的 `owner` 参数，刷新页面仍保留。
- 清空筛选同时移除 `owner`。
- 导出未勾选记录时携带 `owner` 参数，导出当前筛选结果。
- 新增/编辑表单的归属人输入框显示相同的已有值建议，但允许输入新值。
- 新增、编辑或批量修改归属人成功后刷新归属人选项。

归属人选项为空时，下拉框只显示“全部归属人”，不影响新增账号。

## 5. 服务边界

账号服务负责封禁售卖锁定和归属人查询，路由只负责参数校验与响应。

导出路由与列表服务使用相同的 `owner` 精确匹配语义，避免列表和导出结果不一致。

MongoDB 已有 `owner` 索引，不新增集合或单独的归属人数据模型。

## 6. 错误处理

单条或批量操作试图解除封禁账号的“已停用”状态时返回 HTTP 409：

```json
{
  "error": {
    "code": "BANNED_ACCOUNT_SALE_STATUS_LOCKED",
    "message": "封禁账号的售卖状态必须保持为已停用"
  }
}
```

批量错误消息说明被锁定账号数量，但不得返回完整 `sec_uid`、OP卡密或其他敏感值。

## 7. 测试与验收

自动化测试必须覆盖：

- 共享输入契约默认售卖状态为 `recovered`
- 新增封禁账号强制保存为 `disabled`
- 新增正常或违规账号默认保存为 `recovered`
- 修改抖音号、单条重检、批量重检命中封禁时保存为 `disabled`
- 单条和批量操作不能把封禁账号改成其他售卖状态
- 服务启动能修正历史封禁数据
- `owner` 查询精确过滤
- 归属人选项去重、忽略空值并排序
- 归属人筛选同步到导出

浏览器验收必须确认：

- 新增抽屉默认选中“已找回”
- 归属人筛选下拉显示表格中已有归属人
- 选择归属人后 URL、列表和导出链接同步变化
- 新增归属人后无需刷新整站即可出现在下拉选项
- 封禁账号在表格中同时显示“已停用”和“封禁”
